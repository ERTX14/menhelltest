# NOIR Barber Shop — urban chrome edition

Открыть `index.html` — клиентская часть. `admin.html` — панель владельца.

## Что обновлено
- яркая urban/poster эстетика: electric blue, acid lime, hot pink, red + chrome;
- композиция с наклейками, рваными графическими акцентами, outline-словами и техническими подписями;
- плавные reveal-анимации при прокрутке;
- интерактивные карточки услуг;
- hover-анимации Lookbook с лёгким 3D-наклоном;
- магнитные кнопки и кастомный курсор на desktop;
- анимированный прогресс прокрутки и marquee;
- адаптивная mobile-версия;
- в админке можно загрузить/заменить логотип без правки HTML/CSS;
- логотип, название, тексты, контакты, услуги и цены редактируются через панель.

## Логотип
В `admin.html` → `Контент` → `Логотип` можно загрузить PNG/JPG/WebP/SVG до 1 МБ. Логотип хранится в браузере и сразу появляется на клиентской части.

## Заявки
Сейчас заявки работают как frontend-прототип и сохраняются в localStorage. Для реального заказчика следующий этап — подключить PHP/MySQL + Telegram/CRM. UI и панель уже разделены так, чтобы заменить слой хранения без переделки дизайна.
